# Expo Starter

Expo + TypeScript + Expo Router, with ESLint, Prettier, Jest, React Native Testing Library, MSW, and GitHub Actions CI.

## After creating a repo from this template

1. Rename `name` in package.json and `name`/`slug`/`scheme` in app.json
2. `nvm use` and `npm install`
3. Run `npm run lint`, `npm run typecheck`, `npm test`
4. Set up branch protection on main (Settings → Rules)
